# 프로젝트 브리프

## 목적

게임 개발자로서 만든 프로젝트와 문제 해결 과정을 보여주는 개인 포트폴리오 블로그다. 방문자는 짧은 시간 안에 개발 분야, 대표 작업, 기술적 강점을 파악할 수 있어야 한다.

## 주요 독자

- 게임 스튜디오 채용 담당자와 개발자
- 협업 또는 프로젝트 참여를 검토하는 사람
- 기술 글과 TIL을 찾는 동료 개발자

## 핵심 콘텐츠

- 프로젝트 사례: 문제, 역할, 구현, 트러블슈팅, 결과, 배운 점
- TIL: 짧고 재사용 가능한 학습 기록
- 기술 블로그: 하나의 주제를 맥락과 근거를 갖춰 설명하는 글
- About: 관심 분야, 기술 역량, 경력 또는 학습 과정, 연락 경로

## 현재 범위

Astro로 정적 HTML을 생성하는 포트폴리오·기술 블로그다. 홈, 프로젝트 상세, TIL 전체 목록과 개별 글을 제공한다. React는 TIL 목록 필터에 사용하고 글 본문은 빌드 시 HTML에 포함한다.

## 성공 기준

- 모바일과 데스크톱에서 핵심 섹션을 쉽게 탐색할 수 있다.
- 빌드 결과인 `dist/`를 GitHub Pages에서 서버 런타임 없이 제공할 수 있다.
- 새 콘텐츠를 추가할 위치와 작성 기준이 문서에 정의되어 있다.
- React는 필요한 페이지에만 로드하며 JavaScript 없이도 핵심 콘텐츠를 읽을 수 있다.

## 제외 범위

CMS, 본문 검색, 다국어, 복잡한 애니메이션과 서버 렌더링은 현재 범위에서 제외한다. 기존 giscus 댓글은 유지한다.
